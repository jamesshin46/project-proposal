# James Shin - Project Proposal

# Project Title

FlowStack

# What and Why?

Inspired by Jarvis, most calendar apps are not enough for personal organization. Personally, these apps have been useful in inputting data regarding tasks and schedule so that it is visible in a certain manner,
but it is hard to draw insights from it. I am often confused on which tasks to do first, which scheduled items to prioritize, what I should spend my free time doing to be more efficient, and so much more.
I feel that this program will be useful in many ways. First, it will be most important even in its preliminary stages by leveraging AI in order to draw insights from all the tasks there are. Especially with context
regarding what this activity is, it should be able to draw insights regarding the program. However, secondly, it should be able to go even beyond that and truly serve as a foundation for even more, maybe an outfit
recommendation system, or an accountability system.

# For Whom?

This software will be for people like me, who are overwhelmed by all the tasks that they have to do that they do not have enough insight into how to manage their work life in the most effective way possible.

# How?

Since people already are comfortable with the UI / UX of calendar apps, this web app will draw the data regarding tasks, events, and schedules from that app. Then, it will use AI to store this information in a
database, then use that to generate insights regarding what is upcoming at a certain time. Additionally, if there is a free time slot, then the AI will recommend what they need to do or think about during that time.
It will also set a prioritiztion for each of the tasks depending on how the user ranks it, then it will take that in order to enrich its insights further.

# Scope

This project will not be too difficult since it is not composed of many portions - this will mostly be AI engineering and UI / UX design since the app is focused primarily on convenience for the user.
I felt that this project will be most effective to help students think about what is consumer-focused building and how to build something that can actually be of use to people.
